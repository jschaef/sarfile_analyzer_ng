# Standalone dependencies for the SAR Analyzer MCP server (mcp_server/).
# The package imports nothing from code/ or api/ — it is a thin HTTP client of
# the REST API, so these two files (__init__.py + server.py) plus this file are
# all you need on an external host.
#
# Minimum Python: 3.10 (mcp SDK requirement + PEP 604 "X | None" syntax used in
# the code). Tested on 3.12.
# Upper bound is deliberate: mcp 2.x restructured the package and dropped
# mcp.server.fastmcp, which server.py imports. An unpinned install pulled 2.1.0
# onto dus-lab-sar and the service only fell over at its next restart, long
# after the upgrade. Porting to the 2.x API is a separate piece of work.
mcp>=1.26,<2
httpx>=0.27
